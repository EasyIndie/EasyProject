# 持久化记忆（Persistent Memory）

> **🧠 AI Agent 的长期记忆。跨会话保留的上下文信息。**

---

## 这是什么？

`memory/` 是 AI Agent 可以写入持久化信息的地方。与传统会话（每次对话从零开始）不同，Agent 可以在这里存储重要的上下文，供后续会话读取。

---

## 放什么？

- **重要的项目约定**：团队特殊的命名习惯、代码组织偏好
- **已知的坑**：某个库的 bug、某个配置为什么这样设置
- **未完的工作**：当前进行中的功能、被阻塞的任务
- **决策记录**：为什么选了 A 而不是 B（非正式版本，正式版见 ADR）

## 不放什么？

- **代码** → 放在 `apps/` 或 `packages/`
- **架构决策** → 放在 `architecture/adr/`（正式记录）
- **任务** → 放在 `tasks/`
- **需求** → 放在 `specs/`

---

## 文件命名

- 使用 kebab-case
- 名称描述主题
- 示例：`auth-patterns.md`、`known-issues.md`、`current-sprint.md`

---

## 文件格式

```markdown
# 主题名称

## 上下文
（为什么需要记录这个）

## 内容
（具体的信息）

## 更新时间
YYYY-MM-DD — 更新了什么
```

---

## AI Agent 交互指南

1. **每次会话开始时**：浏览 `memory/` 看是否有相关内容
2. **发现重要的上下文时**：写入 `memory/`
3. **信息过期后**：更新或删除对应的记忆文件
4. **不要存储过多信息**：保持精选，信息太多等于没有信息
