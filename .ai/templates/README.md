# 文件模板（Templates）

> **📝 AI Agent 生成新文件时使用的标准模板。**

---

## 这是什么？

`templates/` 存放项目中常用的文件模板。AI Agent 在创建新文件时应该使用这些模板，确保文件格式统一。

---

## 模板列表

| 文件 | 用途 |
|------|------|
| `task-template.md` | 创建新任务文件 |
| `adr-template.md` | 创建架构决策记录 |
| `spec-template.md` | 创建需求规格文档 |
| `code-header.md` | 源代码文件头注释 |

---

## AI Agent 交互指南

- **创建新任务时**：使用 `task-template.md`
- **做重大技术决策时**：使用 `adr-template.md`
- **写需求文档时**：使用 `spec-template.md`
- **创建新代码文件时**：使用 `code-header.md` 的头部格式
