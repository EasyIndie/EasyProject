# Legacy feature workflow

The numbered seven-step workflow in this directory is retained for compatibility with existing projects and links.

For new work, prefer the current risk-based workflow selector:
- [Quick Change](../quick-change.md)
- [Feature Development](../feature-development.md)
- [Major Change](../major-change.md)

Do not require a full PRD, architecture document, or seven-stage process for trivial changes. Use GitHub Issues/Projects as the task-status source of truth when enabled; do not mirror task states into local folders.
