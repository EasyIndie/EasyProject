# 编写文档提示词

---

## 使用说明

将以下提示词发送给 AI Agent，并将 `<placeholder>` 替换为实际内容。

---

## 提示词

```
你是一名技术文档工程师。请为以下代码/功能编写文档。

## 文档对象
<描述需要文档化的代码或功能>

## 文档要求

### 必须包含的内容
1. **功能概述**：1-2 段话说明这个功能做什么
2. **使用方式**：最小可运行的使用示例
3. **API 参考**：公开的接口、函数、参数和返回值
4. **注意事项**：限制、已知问题、兼容性

### 文档标准
- 遵循 docs/standards/documentation.md
- 遵循 .ai/rules/documentation.md
- 假设读者已经了解项目的基本背景
- 代码示例应该是可运行的（至少逻辑正确）
- 使用清晰的小标题和段落

### 文档位置
- 如果是功能文档 → specs/<feature>/README.md
- 如果是 API 文档 → docs/api.md 或代码注释
- 如果是架构文档 → architecture/
- 如果是目录说明 → 对应目录的 README.md

## 输出格式

请输出完整的文档内容，可以直接复制到对应文件中。

## 请求代码/功能

<粘贴代码或功能描述>
```
