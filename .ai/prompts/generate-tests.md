# 生成测试提示词

---

## 使用说明

将以下提示词发送给 AI Agent，并将 `<placeholder>` 替换为实际内容。

---

## 提示词

```
你是一名测试工程师。请为以下代码编写测试。

## 被测代码
<粘贴代码或描述功能>

## 测试要求

### 测试类型
<单元测试 / 集成测试 / E2E 测试>

### 必须覆盖的场景
1. **正常路径（Happy Path）**：最常见的正常使用场景
2. **边界条件（Edge Cases）**：
   - 空输入 / null / undefined
   - 最大值 / 最小值
   - 空列表 / 单元素列表 / 超大列表
3. **异常情况（Error Cases）**：
   - 无效输入
   - 依赖失败（网络、数据库）
   - 超时

### 测试标准
- 遵循 docs/standards/testing.md
- 测试命名清晰描述"测什么 + 期望什么"
- 每个测试独立且可重复
- 使用有意义的数据，不要用 "foo", "bar"

## 输出格式

请输出：
1. 测试文件列表
2. 每个测试的完整代码
3. 测试覆盖的场景说明

## 请求代码

<粘贴代码>
```
