# 重构提示词

---

## 使用说明

将以下提示词发送给 AI Agent，并将 `<placeholder>` 替换为实际内容。

---

## 提示词

```
你是一名代码重构专家。请重构以下代码。

## 重构目标
- 代码文件：<文件路径>
- 重构原因：<为什么需要重构>
- 重构目标：<期望达到的效果>

## 重构原则

### 必须遵守
1. **不改变外部行为**：重构前后，对外部的输入输出完全一致
2. **保持测试通过**：所有现有测试必须继续通过
3. **遵循项目标准**：docs/standards/coding.md 和 .ai/rules/coding.md
4. **渐进式改进**：不要一次改动太多，保持每次改动可审查

### 可以改进的方面
- 消除重复代码
- 改善命名
- 拆分过长函数
- 简化复杂条件逻辑
- 消除魔法数字
- 改善错误处理

### 不要做的
- 不要改变公共 API
- 不要混合重构和新功能
- 不要删除"看起来没用的代码"（先确认真的没用）

## 输出格式

### 重构前后对比
（展示关键变更的前后代码对比）

### 改动说明
（解释每个改动的原因：将 XXX 改为 YYY 是因为 ZZZ）

### 测试验证
（确认哪些测试仍然通过，是否有需要更新的测试）

## 请求代码

<粘贴代码>
```
