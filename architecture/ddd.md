## 什么是 DDD？

领域驱动设计（Domain-Driven Design）是一种软件开发方法，强调将软件模型与业务领域对齐。核心概念：

| 概念 | 说明 |
|------|------|
| **限界上下文** | 一个业务领域的边界，内部有统一的语言和模型 |
| **聚合** | 一组被视为一个单元的对象，有一个聚合根 |
| **领域事件** | 领域中发生的有意义的事情 |
| **通用语言** | 团队共享的业务术语，代码中直接使用 |

## 聚合设计原则

- **小聚合**：一个聚合通常包含 1-3 个实体
- **通过 ID 引用**：聚合之间通过 ID 引用，而非对象引用
- **最终一致性**：跨聚合的操作通过领域事件实现最终一致性
- **事务边界**：一个事务只修改一个聚合
